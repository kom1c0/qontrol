# qontrol — کنترل‌کننده کیفیت یوتیوب

افزونه‌ای سبک برای کروم که کیفیت پخش ویدیوهای یوتیوب را به‌صورت خودکار روی ترجیح شما تنظیم می‌کند و در عین حال تغییرات دستی شما را محترم می‌شمارد. یک‌بار تنظیمش کن — روی همه‌ی ویدیوها اعمال می‌شود.

**زبان:** [English](README.md) | [فارسی](README.fa.md)

## ویژگی‌ها

- اعمال خودکار کیفیت روی هر ویدیو (پیش‌فرض: 1080p)
- فالبک هوشمند — بهترین کیفیت موجود **در حد یا پایین‌تر** از ترجیح شما انتخاب می‌شود؛ هرگز بالاتر از کیفیت انتخابی نمی‌رود
- تشخیص تغییر دستی کیفیت و توقف خودکارسازی؛ با یک کلیک **Reset Manual Override** به حالت خودکار برمی‌گردد
- وضعیت زنده در پاپ‌آپ: Active / Standby / Manual override
- پشتیبانی از ویدیوهای معمولی، Shorts، پلیرهای embed و استریم زنده؛ مدیریت صحیح ناوبری SPA یوتیوب
- رابط کاربری دوزبانه — انگلیسی و فارسی با پشتیبانی کامل RTL؛ شناسایی خودکار زبان مرورگر
- بدون جمع‌آوری داده — همه‌ی تنظیمات به‌صورت محلی در مرورگر ذخیره می‌شوند (`chrome.storage.local`)

**کیفیت‌های پشتیبانی‌شده:** 144p – 4320p (8K)

## نصب

1. کلون کنید (یا سورس رو دانلود کنید)
2. `chrome://extensions` را باز کنید و **Developer mode** را فعال کنید
3. روی **Load unpacked** کلیک کرده و پوشه‌ی `qontrol` را انتخاب کنید
4. آیکون افزونه را پین کنید و کیفیت موردنظرتان را تنظیم کنید

## راهنمای استفاده

- کیفیت موردنظر را در پاپ‌آپ انتخاب کنید — فوراً ذخیره و روی ویدیوی جاری و همه‌ی ویدیوهای بعدی اعمال می‌شود
- اگر کیفیت را دستی از تنظیمات یوتیوب تغییر دهید، qontrol به حالت **Manual override** می‌رود و از مداخله باز می‌ایستد
- برای بازگشت به حالت خودکار، **Reset Manual Override** را بزنید

## معماری

طراحی سه‌لایه با Manifest V3، همراه با پل ارتباطی به کانتکست صفحه برای دسترسی به پلیر یوتیوب:

| لایه | فایل | نقش |
|---|---|---|
| پاپ‌آپ | `popup/` | رابط کاربری — خواندن/نوشتن ترجیحات و زبان، polling تب فعال برای وضعیت زنده |
| Service worker | `background/service-worker.js` | ورکر MV3 — مقادیر پیش‌فرض، رله‌ی پیام‌ها |
| Content script | `content/youtube.js` | دنیای ایزوله — نظارت بر ناوبری SPA، تزریق اسکریپت صفحه، پل‌کردن پیام‌ها |
| Page script | `content/injected.js` | کانتکست صفحه — دسترسی به API پلیر یوتیوب (`getAvailableQualityLevels`، `setPlaybackQualityRange`…)، اعمال کیفیت، تشخیص تغییرات دستی، ریست برای هر ویدیو |

ارتباط بین دنیاهای مجازی با `window.postMessage` + `CustomEvent` و بین اجزای افزونه با `chrome.runtime` / `chrome.tabs` انجام می‌شود.

## تکنولوژی‌های به‌کار رفته

- **Chrome Extension — Manifest V3** (سرویس‌ورکر، بدون صفحه‌ی background دائمی)
- **JavaScript خالص (ES2020+)** — بدون فریمورک، بدون مرحله‌ی build
- **Chrome APIs** — `runtime`، `storage.local`، `tabs`، `scripting`، `i18n`
- **YouTube player API** — سازگار با صفحه‌ی اصلی، `#movie_player` و iframeهای embed
- **مدیریت SPA** — `MutationObserver`، هوک‌های `pushState/replaceState`، `popstate`، `visibilitychange`
- **UI** — HTML5 + CSS3، سلکتور popover سفارشی (بدون کتابخانه)، تم تاریک
- **تایپوگرافی** — فونت وزیرمتن (خودمیزبان، woff2)
- **i18n** — `chrome.i18n` + `_locales/{en,fa}`، تغییر زبان در زمان اجرا با RTL

## دسترسی‌ها (Permissions)

| دسترسی | دلیل |
|---|---|
| `storage` | ذخیره‌ی محلی کیفیت ترجیحی و زبان |
| `tabs` | وضعیت زنده‌ی تب فعال در پاپ‌آپ |
| `scripting` | کنترل content script در MV3 |
| `https://*.youtube.com/*` | تزریق تنها در صفحات یوتیوب |

## پشتیبانی مرورگرها

کروم و مرورگرهای مبتنی بر Chromium (Edge، Brave، Opera، Vivaldi) — نسخه ۸۸ به بالا. فایرفاکس پشتیبانی نمی‌شود.

## بومی‌سازی

دو زبان **انگلیسی** و **فارسی** همراه افزونه است. زبان مرورگر به‌صورت خودکار تشخیص داده می‌شود و از طریق پاپ‌آپ قابل تغییر است. برای افزودن زبان جدید، فایل `_locales/<code>/messages.json` را با همان کلیدهای نسخه‌ی انگلیسی بسازید.
